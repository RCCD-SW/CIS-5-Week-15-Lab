## Getting started

1. Fork this repo on GitHub.
2. Clone your fork.
3. Create your own `main.cpp` in this repo (do not start a second language).
4. Compile and run:

```bash
g++ -std=c++17 -o program main.cpp && ./program
```

5. Record a **2–3 minute** demo that shows your tool, a walkthrough of the design, and a real run.
6. Paste the video link in the **Demo video** section above.
7. Submit your fork URL on Canvas.
